NameToColor Multi-Language

One shared database, one contract, four languages. Core (calculation + search) is separated from DOM / Widget interface in every implementation.

Shared base JSON

Files: shared/colors.json (2,254 colors) + shared/languages.json (pt-BR aliases, moods, temperature, theme mappings).

All submodules import these — zero duplication.

Submodules

JavaScript Vercel CDN Node

Core: js/nameToColor.js — full contract (generateColor, colorName, listColors, mood, temperature, isReadableForBlindness, etc.). Hybrid loader: reads shared/colors.json in Node/Vercel; falls back to embedded DB for CDN.

DOM: js/dom.js — applyToElement, applyGenerateColorToElement.

Usage (CDN): <script src="https://zonaro.github.io/NameToColor/js/nameToColor.js"></script> — then call generateColor("hello").

Usage (Vercel/Node): const lib = require('./js/nameToColor.js');

Dart Flutter

Core: dart/lib/nameToColor.dart — same contract, reads shared/colors.json.

Widgets (DOM equivalent): dart/lib/dom.dart — NameToColorWidget, NameToColorText.

PHP Core only

Core: php/src/nameToColor.php — class with full contract. No DOM needed.

C# Core only

Core: cs/NameToColor/NameToColor.cs — compiled library (dotnet build passes).

Quick start all languages

JS (browser / CDN):

<script src="js/nameToColor.js"></script>
<script>console.log(generateColor("hello"));</script>

Dart (Flutter widget):

import 'package:myapp/lib/dom.dart';
NameToColorWidget(input: "hello", color: Color(0xFF4C4F56))

PHP:

require 'php/src/nameToColor.php';
$hex = NameToColor::generateColor('hello');

C#:

using NameToColor;
var hex = NameToColorCore.GenerateColor("hello");
